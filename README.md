# nba-game-prediction

# NBA Game Outcome Prediction (2013–2023)

UTS Machine Learning Project evaluating Logistic Regression, Lasso Regression, and Optuna-tuned XGBoost on 10-game rolling efficiency metrics.

## Quick Links
* **Google Colab Notebook:** [https://colab.research.google.com/drive/1VLGXWgtbi1zDoCUdD4DEPmGeRbFkK0QA#scrollTo=FB_YP532nbNZ]
* **Dataset:** `games.csv` (10-season NBA box-score data)

## Key Results
* **Lasso Regression:** 60.05% Test Accuracy (Top Model)
* **Baseline Logistic Regression:** 59.97% Test Accuracy
* **Optuna XGBoost:** 59.17% Test Accuracy
